# ISO 14001 Course Activities

Eight connected activities for **Fundamentals of ISO 14001 Environmental Management System (EMS)** (TGS-2023037592). Each folder is self-contained and includes a detailed Markdown/PDF procedure, printable scenario/checklist and editable Excel evidence workbook.

- [Activity A1 - Build the Environmental Baseline and Aspect Inventory](activity-01-environmental-baseline-aspects/README.md) - A1
- [Activity A2 - Assess Significance, Risks and Opportunities](activity-02-significance-risks-opportunities/README.md) - A2
- [Activity A3 - Build the Compliance Obligations Register](activity-03-compliance-obligations-register/README.md) - A4
- [Activity A4 - Set Environmental Objectives and Build Competence](activity-04-objectives-kpis-competence/README.md) - A6
- [Activity A5 - Design Life-Cycle Operational Controls](activity-05-lifecycle-operational-controls/README.md) - A5
- [Activity A6 - Run an Environmental Emergency Tabletop](activity-06-environmental-emergency-tabletop/README.md) - A3, A4
- [Activity A7 - Evaluate Performance and Conduct an Internal Audit](activity-07-performance-compliance-internal-audit/README.md) - A5, A6
- [Activity A8 - Close Corrective Action and Plan the 2026 Transition](activity-08-corrective-action-2026-transition/README.md) - A7, A8

## Learning sequence

The Meridian EcoPack journey progresses from environmental baseline and significance through compliance, objectives, life-cycle controls and emergency response, then uses performance evaluation, audit, corrective action and controlled ISO 14001:2026 transition planning to close PDCA.
